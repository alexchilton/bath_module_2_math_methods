# Mathematical Methods for AI — Module 2
**University of Bath**

Lecture notes and problem sets covering the mathematical foundations required for AI and computer science — from discrete mathematics and linear algebra through to probability theory and statistical inference.

---

## Topics Covered

| Area | Concepts |
|------|----------|
| **Logic** | Propositional logic, predicate logic (∃, ∀), truth tables, tautologies |
| **Set Theory** | Cardinality, power sets, distributive laws, inclusion-exclusion principle |
| **Functions** | Injectivity, surjectivity, inverse functions, binary relations, equivalence classes |
| **Linear Algebra** | Matrix operations, determinants, inverses, systems of equations (Ax = b) |
| **Eigenanalysis** | Eigenvalues and eigenvectors, geometric interpretations (rotation, reflection, scaling) |
| **Calculus** | Differentiation (chain, product, power rules), integration by parts, continuity |
| **Discrete Probability** | Probability spaces, PMF/CDF, conditional probability, Bayes' theorem, Poisson distribution |
| **Continuous Probability** | Uniform, exponential distributions, PDF/CDF derivations, variable transformations |
| **Statistics** | Sample means, covariance, correlation, hypothesis testing, Type I/II errors |
